# Examples

Run from repository root with a QGIS-enabled Python environment.

## Simplify

```bash
python examples/run_simplify.py
```

## Reduce Bend

```bash
python examples/run_reduce_bend.py
```

## Chordal Axis

```bash
python examples/run_chordal_axis.py
```

Optional:

- Set `QGIS_PREFIX_PATH` if your QGIS runtime is not auto-discovered.
